🎨 Estilo do TFT

🖥️ Telas do TFT (ordem)

A página 1 é exibida primeiro ao ligar. Você pode definir as páginas 1-11 ou desativá-las (OFF).
Troca automaticamente a tela do TFT um passo para a direita.
Intervalo entre as trocas automáticas de tela (1-3600 s).

Restaura a calibração padrão do touch definida no firmware

ALERTA APRS

🚨 ALERTA APRS

Campo CSV único. Máximo de 20 entradas. Exemplo: SQ3NIK-9, SP3YOR, SP3KON* (* no final = qualquer SSID)
Quando desativado, a lista continua salva, mas os alertas não são informados.
0 = alerta a cada recepção. Faixa: 0-86400 segundos.
Faixa: 1-60 segundos. Padrão: 5 segundos.
Vale apenas para estações APRS com SSID -7 ou -9 (ex.: SP3KON-9, SQ3NIK-7).
Quando ativado, o ALERTA APRS também detecta estações com o símbolo WX e mostra um alerta com os dados meteorológicos decodificados.
O alerta dispara para estações móveis a esta distância ou menos.
Liga ou desliga o LED piscante do ALERTA APRS. Dá para soldar um buzzer de 3V.
Faixa: 100-60000 ms. Padrão: 5000 ms.
Faixa: 50-5000 ms. Padrão: 500 ms.

ALERTA DE CLIMA

⚡ ALERTA DE CLIMA

Mostra um alerta quando a previsão das próximas 6 horas indicar possível tempestade.
Mostra um alerta quando a previsão das próximas 6 horas indicar vento forte.
Define o limite de velocidade do vento para os alertas (faixa 1,0-60,0 m/s).

Configuração do ESP32-HAM-CLOCK

📶 Conexão WiFi

Nome da rede WiFi à qual o dispositivo deve se conectar
Senha do WiFi (deixe vazio para redes abertas)
SSID secundário usado quando o principal não estiver disponível
Senha da rede reserva (deixe vazio para rede aberta)

🔌 Porta serial UART

O padrão é 9600. Use a mesma taxa nos dois lados.
O valor típico é 8 para módulos GPS e HC-05.
Pinos da UART2: RX = IO27, TX = IO22 (ESP32).
GPS: Inativo FIX: Não
Módulo BT: Inativo

📻 DX Cluster

Endereço do servidor DX Cluster (ex.: dxc.metronet.pl ou dxspots.com)
Porta do servidor DX Cluster (normalmente 23 para Telnet)
Oculta os anúncios administrativos do cluster
Oculta os boletins WWV (relógios atômicos)
Oculta os boletins WCY (relógios atômicos)
Ativa filtros avançados de spots (requer os comandos abaixo)
Comandos de filtro para o CC-Cluster. Exemplos: set/filter k,ve/pass (somente K e VE), set/filter dxbm/pass hf (somente HF), set/filter dxbm/reject 6-cw,6-ssb,6-fm (rejeitar 6 m)

🏕️ POTA Cluster

Endereço usado pelo backend para buscar os spots do POTA (HTTP JSON)

🛰️ HAMALERT

Opcional. Padrão: hamalert.org
Opcional. Padrão: 7300
Opcional. Login da conta HamAlert para autenticação Telnet
Opcional. O HAMALERT fica desativado se login/senha estiverem vazios

📡 Sua estação

Seu indicativo, usado para entrar no DX Cluster
Locator Maidenhead (4-6 caracteres) usado para calcular as distâncias dos spots
Deslocamento em horas em relação ao UTC (ex.: Brasília: -3)
Latitude em formato decimal (como no Google Maps). Exemplo: -23.5505 para São Paulo
Longitude em formato decimal (como no Google Maps). Exemplo: -46.6333 para São Paulo
Quando ativado e o GPS tiver FIX, todos os serviços usam as coordenadas do módulo GPS em vez das coordenadas manuais da estação.

🔍 QRZ.com

Usuário da API do QRZ.com (opcional, para informações extras do indicativo)
Senha da API do QRZ.com (opcional)
Status da conexão com o QRZ.com (atualizado automaticamente)

🌤️ OpenWeather

Chave da API do openweathermap.org (necessária para mostrar clima e previsão nas telas do TFT)

📡 KiwiSDR

Informe o endereço do KiwiSDR pelo qual deseja ouvir as estações, ex.: http://okno.ddns.net:8073/ Lista de KiwiSDR disponíveis: http://kiwisdr.com/.public/

📻 APRS-IS

Endereço do servidor APRS-IS (ex.: rotate.aprs2.net)
Porta do servidor APRS-IS (padrão 14580)
Seu indicativo, usado para entrar no APRS-IS
SSID acrescentado ao indicativo na transmissão do beacon APRS. 0 = sem sufixo.
Passcode do APRS-IS (gere em aprs.org)
Raio do filtro de estações APRS em quilômetros (0-50 km). O filtro e todos os cálculos de distância usam as coordenadas da seção "Sua estação" (formato xx.xxxxxx)
Envia sua posição periodicamente (TCPIP*). Requer coordenadas configuradas.
O primeiro caractere é a tabela (ex.: / ou \), o segundo é o símbolo (ex.: -). Usado no beacon.
Máximo de 43 caracteres ASCII. Usado em todo beacon; o primeiro e a cada cinco beacons usa o link do projeto ESP32-HAM-CLOCK.
Intervalo entre beacons consecutivos após o primeiro (enviado em 1 minuto). Faixa 1-180 min.
